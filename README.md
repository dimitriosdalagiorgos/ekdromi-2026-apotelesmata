# Εκδρομή Γ' Λυκείου 2026 — αποτελέσματα

Ζωντανά αποτελέσματα της ταξινομικής ψηφοφορίας (instant-runoff) για τον προορισμό της εκδρομής.

Η σελίδα (`index.html`) διαβάζει, κάθε φορά που ανοίγει ή όταν πατηθεί «Ανανέωση», το συγκεντρωτικό φύλλο Google «rcv123 - 2026»:

- καρτέλα «1 απαντήσεις φόρμας», στήλες D:I: μία γραμμή ανά ψηφοδέλτιο «Ναι», με τη θέση που έδωσε ο ψηφοφόρος σε κάθε προορισμό. Τη γεμίζει ο τύπος `QUERY(IMPORTRANGE(...))` στο D2.
- καρτέλα «meta», κελί B1: η ώρα της τελευταίας ψήφου «Ναι».

Το φύλλο περιέχει μόνο κατατάξεις, όχι ονόματα ή email. Αν το φύλλο δεν απαντήσει, η σελίδα δείχνει το αποθηκευμένο στιγμιότυπο που έχει μέσα της.
